# Max Kristoffersson — Portfolio

Personlig portfolio med cyber-minimalistisk design och interaktiv terminal.

## Sidor

- **index.html** — Landing page med interaktiv terminal
- **projects.html** — Projektgalleri
- **cv.html** — Digitalt CV med utskriftsstöd

## Deploy till GitHub Pages

1. Ladda upp filerna till repots root (`main`-branchen)
2. Gå till **Settings → Pages**
3. Under *Source*, välj **Deploy from a branch → main → / (root)**
4. Klicka **Save** — sidan är live på `https://DH-stream.github.io/portfolio_maximo/`

## Anpassa

- **LinkedIn-länk**: Sök efter `linkedin.com/in/` i alla filer och ersätt med din riktiga URL
- **Projekt**: Redigera korten i `projects.html`
- **A-kod-bild**: Byt `assets/projects/a-kod-automation-placeholder.svg` mot din anonyma screenshot och uppdatera `image`-fältet för A-kod Automation i `index.html`.
- **Terminal-kommandon**: Redigera `COMMANDS`-objektet i varje sidas `<script>`-tag

## Design System

Cyber-minimalistisk — mörk bakgrund med neon-cyan accenter, glassmorfism-kort och JetBrains Mono för kod-element.
